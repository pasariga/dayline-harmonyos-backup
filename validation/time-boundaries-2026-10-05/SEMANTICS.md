# V1.0 时间语义（修改前决策，2026-10-05）

| 值 | 语义 | 时区改变时 |
| --- | --- | --- |
| Deadline 日期/时间输入 | 保存时设备当地日历和钟面；用户指定到分钟 | 新选择按当时设备时区解释；已保存项从 deadline_at 显示 |
| deadline_at | 固定 UTC epoch 毫秒，是权威截止时刻 | 不改变，只换当地显示；普通字段编辑保留原日期三元组 |
| deadline_date / deadline_time | 兼容保留的原录入文字，不含源时区 | 不反推、不重写已有截止时刻；不能准确恢复历史来源时区 |
| created_at / task created_at | 绝对时刻 | 不改；显示当地日期 |
| remaining_updated_at | 最近确认的绝对时刻 | 不改；有效期仍为 14×24 小时的持续时间，不是14次午夜 |
| scheduled_at | 实际计划发布的绝对时刻，本机状态 | 本地时间类候选重新计算，截止时刻不变 |
| 1小时前 | 真实持续时间60分钟 | 固定截止时刻减60分钟 |
| 1天/3天前 | 当前设备时区的前1/3个日历日、同钟面 | 重新计算，不减固定24/72小时 |
| 每日摘要 | 当地钟面时间，每自然日一个日期键 | 按新时区当地日期/钟面重算；不补发过去摘要 |
| 免打扰 | 当地重复钟面区间，开始含/结束不含，支持跨午夜 | 按新时区重算，不是固定UTC区间 |
| 今天 / 剩余N天 | 当前设备时区日历日期、日期序数差 | 重算；近距离小时提示仍表示真实持续时间 |
| 自动倒排日/每日容量 | 当地午夜到下一午夜；23/25小时仍是一日 | 自然日逐日推进，每日容量不因日长变成2.875/3.125小时 |
| 风险与截止剩余小时 | 固定截止时刻与当前绝对时间之差，容量按当地日历分段 | 重算，不移动截止 |
| 同步事件/历史时间 | 绝对审计时间，不用于因果排序 | 完全冻结；不重解释、不改载荷 |
| 活动冷却、风险限频、逾期小时 | 持续时间 | 沿用现有策略；不是自然日运算 |

现有库足以表达固定时刻，无需升级、回填或迁移。来源时区丢失的旧文字不能作为可信时区；V1.0不新增全球日历模型。编辑未改截止时保留原三元组，避免旅行/秋季重叠小时导致静默移动。

创建已过去的时刻：保留草稿并在日期处提示改选未来；编辑历史允许过去时间。新选择落在春季不存在的钟面时间时拒绝自动偏移；秋季重叠时间要求改选明确时间，避免静默猜一个时刻。已经保存的重叠时刻普通编辑仍保留原绝对值。

14×24小时有效期保持工作量模型既有规则；14个自然日跨DST可能相差1小时，测试明确验证两者的区别。系统时间回拨到确认之前时不把负年龄当新鲜，暂降级但保留原数字/时间；时间恢复后重算。无可信外部时钟时不能确定真实年龄，不另建后台机制。

先发现：Schedule日数用 floor(当地午夜毫秒差/24h)，春季少一天；详情次要日期/时间读旧录入文字；编辑普通字段重建当地时刻；1/3天提醒减固定24h；页面仅低频刷新，已有系统时钟事件只触发通知协调。

验证须分别记录生产代码自动化、Phone实际运行、未完成真实时区/DST和真实系统通知送达。Calendar/Timer 1700002 保留真机发布前门禁，不在本轮重新诊断。
