# 信息层级、元素与颜色专项验收（2026-10-03）

## 范围与结论

仅修改 Index、DeadlineDetail、CreateDeadline、CloudAccount 四个页面及九套 messages 资源；没有改 service、模型、数据库结构/版本、风险/排期/工作量、同步、通知、主题机制或身份配置。服务文件 SHA-256 逐一对比不变。新增两项文案（下一步、任务操作），九套 messages 各 345 键一致、无重复。

本轮信息层级目标完成：一个主视觉焦点，风险作为文字状态；不继续大型视觉重构。本结论是当前 Phone 默认字号的布局验收，不是学生可用性研究或全尺寸/大字体验收。

## 首页 A/B/C/D

| 等级 | 信息 | 展示方式 |
| --- | --- | --- |
| A 首屏必须 | 今日首要行动、所属 Deadline、下一步操作 | 最大行动标题及唯一主要按钮；空状态改为创建第一项 |
| B 辅助 | 截止紧迫性、风险、创建/设置入口 | 行动原因和文字状态；创建为页首中性加号，有无障碍名称 |
| C 下方或按需 | 接下来、全部 Deadline、自动倒排 | 紧凑行；列表仅名称/日期/状态；倒排放在列表之后，默认收起 |
| D 移出独立首页指标 | 任务百分比、剩余量指标、总完成比例、统计、重复风险/稍后分组 | 任务与剩余量到详情；行动理由必要时仍保留影响判断的工时，不新增统计页 |

保留列表排序与规划结果；删除“其他风险/稍后再做”重复列表，不遗漏原 Deadline。主页不再为每个 Deadline 单独画卡片或风险 Pill，不给低风险/未知数据染色；未安排工作仍在展开排期中可见。

## 详情三层

1. 名称、截止/完成状态、下一步；第一未完成叶子来自已有任务顺序，完成调用原 toggleTask（含原事务/冲突保护）。
2. 任务数量进度、风险文字、当前剩余量；估计更新为次要入口，编辑展开后保存才成为主要操作。总工时移到详情展开区。
3. 完整任务树、按需排期/风险解释/总工作量/类型/提醒/备注；任务操作逐项展开，最多一项展开，不把 0%/100% 放在每个叶子后面。

手动模式仍只有现有手动进度控件，不额外增加一个工作量百分比。完成、取消完成及撤销使用原保存路径。任务操作与完成点击目标分开，菜单点击不改变完成状态。

## 颜色规则

品牌色用于主要操作、选中和可交互入口；红色用于真实高风险、错误和删除；橙色用于中等风险/需要处理的警示；绿色用于完成/成功；普通名称、日期、小时、未知及低风险大多用中性色。未知不等于危险。风险必有文字。移除装饰色条、风险色工时、日期/排期 Pill 和大块完成绿底；普通退出登录按钮也改为中性色，原确认流程未改。

首屏一个主视觉焦点；必要风险提示是从属警示，不新增多个主按钮。设置目录与简单二级设置已符合层级，因此保留原布局。
